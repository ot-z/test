运行说明
  • 启动：双击项目根目录的 start.bat，或运行 node app/server.js
  • 停止：在运行窗口按 Ctrl + C
  • 备份：复制 app/data/ 目录即可；恢复后重启服务
  • 零依赖：不需要 npm install，前端也不加载任何 CDN
